## คู่มือการใช้งาน Fuki-MicroCap-Bot (trading_script.py)

### 1. เตรียมสภาพแวดล้อม (Environment)
- ติดตั้ง Python 3.13 (หรือตามที่คุณใช้อยู่)
- เปิด Terminal / PowerShell ในโฟลเดอร์โปรเจกต์ `Fuki-MicroCap-Bot`
- ติดตั้งไลบรารีที่ต้องใช้:

```bash
pip install -r requirements.txt
```

### 2. ค่าตั้งต้นสำคัญในสคริปต์
เปิดไฟล์ `trading_script.py` จะเห็นตัวแปร `CFG` กำหนดค่าต่าง ๆ เช่น:
- `CASH` : ทุนตั้งต้น (เช่น 10,000 ดอลลาร์)
- `STOP_LOSS_PC` : เปอร์เซ็นต์จุดตัดขาดทุน (เช่น 0.05 = 5%)
- `MAX_POS_PC` : สัดส่วนสูงสุดต่อ 1 หุ้น (เช่น 0.20 = 20% ของพอร์ต)
- `TICKERS` : รายชื่อสัญลักษณ์หุ้น/ETF ที่ต้องการเทรด (เช่น `["SPY","IWM"]`)
- `PORTFOLIO_CSV` : ไฟล์เก็บสถานะพอร์ตปัจจุบัน
- `TRADES_CSV` : ไฟล์ล็อกประวัติการซื้อ–ขาย

หากต้องการเปลี่ยนกลยุทธ์ (เช่น ใช้ micro-cap อื่น ๆ) ให้แก้ไขที่ `TICKERS` และค่าที่เกี่ยวข้องใน `CFG`

### 3. การรันบอทเทรด
ในโฟลเดอร์โปรเจกต์ รันคำสั่ง:

```bash
python trading_script.py
```

เมื่อรันแต่ละครั้ง สคริปต์จะ:
1. ดึงราคาล่าสุดของหุ้นใน `TICKERS` ผ่าน `yfinance`
2. โหลดพอร์ตจาก `Scripts and CSV Files/portfolio.csv`
3. คำนวณจำนวนหุ้นที่ควรซื้อ (ตาม `CASH` และ `MAX_POS_PC`) หากยังไม่มีสถานะในสัญลักษณ์นั้น
4. ตั้ง Stop-loss ตาม `STOP_LOSS_PC`
5. ถ้ามีสถานะอยู่แล้ว จะตรวจว่าราคาลงมาต่ำกว่าราคา Stop หรือไม่ ถ้าต่ำกว่าจะขาย (STOP) ออก
6. บันทึกการซื้อ–ขายลง `trades_log.csv`

### 4. ไฟล์สำคัญที่ต้องรู้
- `Scripts and CSV Files/portfolio.csv`  
  เก็บสถานะพอร์ตปัจจุบัน: คอลัมน์ `symbol, shares, entry_price, stop`

- `Scripts and CSV Files/trades_log.csv`  
  เก็บประวัติการเทรดทุกครั้ง: `datetime, symbol, side, shares, price`

หากไฟล์เหล่านี้ยังไม่มี สคริปต์จะสร้างให้โดยอัตโนมัติเมื่อรันครั้งแรก

### 5. การติดตามผลและการใช้งานซ้ำ
- คุณสามารถเปิดดู `portfolio.csv` เพื่อตรวจสอบว่าตอนนี้ถืออะไรอยู่ กี่หุ้น ราคาทุน และ Stop ที่ตั้งไว้เท่าไร
- เปิดดู `trades_log.csv` เพื่อติดตามบันทึกการซื้อ–ขายย้อนหลัง
- สามารถรัน `python trading_script.py` ซ้ำได้เรื่อย ๆ (เช่น รันด้วย Cron/Task Scheduler หรือกดรันเองเป็นระยะ) เพื่ออัปเดตสถานะตามราคาตลาดล่าสุด

### 6. การปรับแต่งเพิ่มเติม
- ปรับ `CASH`, `STOP_LOSS_PC`, `MAX_POS_PC` ตามระดับความเสี่ยงที่ต้องการ
- ปรับ `TICKERS` ให้เป็นหุ้น/ETF หรือ micro-cap ที่คุณต้องการทดสอบกลยุทธ์
- ถ้าต้องการเชื่อมต่อกับโบรกเกอร์จริง ต้องเพิ่มโค้ดเชื่อม API แทนการบันทึกเฉพาะใน CSV (ตอนนี้สคริปต์ทำงานในเชิงจำลอง/บันทึกสถานะเท่านั้น)

หากต้องการให้ช่วยออกแบบกลยุทธ์ เพิ่มเงื่อนไขซื้อ–ขาย หรือสร้างกราฟวิเคราะห์จาก `portfolio.csv` / `trades_log.csv` แจ้งได้เลย

## แนวทางทดลองเลือกหุ้น Micro-Cap ด้วย ChatGPT + `trading_script.py`

โฟลเดอร์นี้ออกแบบให้คล้ายกับ `Experiment Details` ของโปรเจกต์ต้นฉบับ เพื่อใช้จัดระเบียบการทดลองเลือกหุ้น micro-cap ของคุณเอง

### 1. โครงสร้างไฟล์ในโฟลเดอร์นี้

- `README.md` (ไฟล์นี้)  
- `MicroCap_Selection_Prompt.md` — ตัวอย่าง prompt ภาษาอังกฤษ/ไทย สำหรับถาม ChatGPT ให้ช่วยคัดหุ้น micro-cap  
- `Candidate_MicroCaps.csv` — รายชื่อหุ้น micro-cap ที่เลือกได้จาก ChatGPT หรือการรีเสิร์ชอื่น ๆ

### 2. วิธีใช้ร่วมกับ `trading_script.py`

1. ใช้ไฟล์ `MicroCap_Selection_Prompt.md` เป็นต้นแบบคำถามเวลาคุณคุยกับ ChatGPT เพื่อขอรายชื่อหุ้น micro-cap  
2. นำรายชื่อหุ้นที่สนใจไปเติมใน `Candidate_MicroCaps.csv`  
3. เลือกหุ้นชุดสุดท้าย (เช่น 5–10 ตัว) แล้วนำไปใช้เป็น universe หลักของคุณ (เช่น ปรับ `tickers.json` ให้เป็นหุ้นเหล่านี้ หรือใช้เป็น watchlist ส่วนตัว)  
4. ใช้ `trading_script.py` เพื่อ:
   - ติดตามผลการเทรด/มูลค่าพอร์ตผ่าน `Daily Updates.csv`
   - บันทึกการซื้อ–ขายผ่าน `Trade Log.csv`

### 3. กติกาเข้า–ออกเบื้องต้นสำหรับ Mid-Cap (ใช้คู่กับ `trading_script.py`)

ตัวอย่างกติกาที่เหมาะกับ mid-cap (เสี่ยงน้อยกว่า micro-cap แต่ยังเติบโตได้ดี):

- **จักรวาลหุ้น (Universe)**  
  - ใช้หุ้น mid-cap จาก prompt ใน `MidCap_Selection_Prompt.md`  
  - คัดเหลือ ~5–20 ตัวที่คุณเข้าใจธุรกิจชัดเจน และมีสภาพคล่องดี

- **สัญญาณซื้อ (Entry Rules)** – ใช้ร่วมกับกราฟ/เว็บภายนอก
  - ราคาปัจจุบันอยู่เหนือ **เส้นค่าเฉลี่ย 50 วัน (MA50)**  
  - และ MA50 อยู่เหนือ **MA200** (แนวโน้มหลักเป็นขาขึ้น)  
  - หรือ ราคาเบรกจุดสูงสุด **20 วัน** (20-day breakout) พร้อมปริมาณการซื้อขายวันนี้ > 1.5× ค่าเฉลี่ย 20 วัน
  - Stop-loss เริ่มต้น: 8–12% ต่ำกว่าราคาเข้าซื้อ (แล้วบันทึกใน `trading_script.py` ตอน BUY)

- **สัญญาณขาย (Exit Rules)**
  - **Cut Loss**: ถ้าราคาลงต่ำกว่าจุด stop-loss ที่ตั้งไว้ ให้ปล่อยให้ระบบขายอัตโนมัติ (โค้ดมีส่วน `SELL - Stop Loss Triggered` แล้ว)  
  - **ขายทำกำไร**:  
    - เมื่อกำไรถึง +20–30% ให้ขายครึ่งหนึ่ง แล้วเลื่อน stop-loss ของส่วนที่เหลือขึ้นมาแถวราคาเข้าซื้อ (break-even) หรือใต้ MA50 เล็กน้อย  
  - **แนวโน้มเสีย**:  
    - ถ้าราคา **ปิดต่ำกว่า MA50 สองวันติด** และ MA50 เริ่มหันหัวลง ให้พิจารณาขายออกทั้งหมดแม้จะยังไม่ถึง stop-loss เดิม

- **ขนาดสถานะ (Position Sizing)**
  - จำกัดความเสี่ยงต่อหุ้นไม่เกิน **2% ของทุนรวม** (เช่น มี 10,000 USD เสี่ยงต่อหุ้น 200 USD)  
  - ใช้ stop-loss คำนวณจำนวนหุ้น เช่น  
    - เสี่ยง 200 USD, stop-loss 10% → มูลค่าซื้อได้ 2,000 USD ต่อหุ้น → จำนวนหุ้น = 2,000 / ราคาเข้าซื้อ

คุณสามารถบันทึกการตัดสินใจซื้อ–ขายตามกติกานี้ลงใน `Trade Log.csv` (ผ่านเมนู interactive ของ `trading_script.py`) แล้วใช้ `Generate Graph.py` ดูผลเทียบกับ S&P 500 ได้

### 4. การบันทึกการทดลอง (Experiment Log)

คุณสามารถเพิ่มไฟล์ใหม่ เช่น:

- `Experiment_Log_YYYYMMDD.md`  
  เพื่อจด:
  - วันที่
  - รายชื่อหุ้น micro-cap ที่เลือก
  - เหตุผล/ธีมการลงทุน
  - กติกาการเข้า–ออก
  - ข้อสังเกตหลังผ่านไป X วัน/สัปดาห์
